# Definition of Done

Una tarea se considera completada cuando cumple todos los siguientes puntos.

## Requisitos

- Código implementado
- Código revisado
- Tests añadidos o actualizados
- Tests pasando
- Documentación actualizada
- Sin errores conocidos

## Validación

Antes de cerrar la tarea se debe verificar:

- La funcionalidad funciona correctamente
- El código sigue las convenciones del proyecto
