# Peer Review

Todas las contribuciones deben pasar revisión antes de ser integradas.

## Proceso

1. Crear Pull Request
2. Un revisor asignado revisa el código
3. Se sugieren cambios si es necesario
4. Cuando todo está correcto se aprueba el PR

## Qué revisar

- Calidad del código
- Claridad y legibilidad
- Cumplimiento de la arquitectura
- Posibles bugs
- Tests

## Reglas

- No se puede mergear sin al menos **1 aprobación**
- Resolver todos los comentarios antes del merge (si es necesario)
